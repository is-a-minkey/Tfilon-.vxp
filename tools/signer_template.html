Tfilon for MRE – sign it for your SIM

Nokia Series 30+ phones (225, 220, 215, 5310 ...) only run an MRE app (.vxp) that carries the IMSI of the SIM card inside the phone. Type your IMSI and this page builds your personal Tfilon.vxp. Everything happens inside this page: nothing is uploaded and no internet connection is needed.

Then
  1. Copy the downloaded file to the phone or its memory card (the MRE folder is the usual place).
  2. Open it from the phone’s file manager (or the Apps menu).

The file only works with the SIM whose IMSI you entered. With a different SIM, create a new file here (it takes a few seconds).

Where do I find my IMSI?
  • The easiest way reported by the MRE community: put the SIM into an Android phone and read it there – some phones show it under Settings → About phone → Status, otherwise use any “SIM info” app.
  • With USB debugging on, adb shell service call iphonesubinfo 1 prints it (the digits are spread over the output).
  • Your mobile operator can also tell you.
  • It is not the IMEI (the phone’s serial number) and not the number printed on the SIM card. On a dual-SIM phone use the SIM in slot 1 (the community advice) – if that does not start the app, try the other SIM.
